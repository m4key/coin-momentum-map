# Coin Momentum Map

Создай современный веб-интерфейс криптовалютного скринера под названием Crypto Metrics.

Цель приложения — помогать трейдеру анализировать альткоины и находить потенциальные торговые возможности.

Требования к интерфейсу:

1. Используй тёмную тему и лаконичный профессиональный дизайн, характерный для аналитических платформ.
2. В верхней части страницы размести название Crypto Metrics и краткую сводку состояния рынка.
3. Создай таблицу криптовалют со столбцами:
   - Название и тикер.
   - Текущая цена.
   - Изменение цены за 24 часа.
   - Объём торгов за 24 часа.
   - RSI.
   - Торговый сигнал.
4. Добавь фильтры по названию монеты, изменению цены и торговому сигналу.
5. Добавь несколько демонстрационных криптовалют: BTC, ETH, SOL, SUI и LINK.
6. Сделай таблицу удобной для сортировки и просмотра.
7. Используй адаптивный дизайн, чтобы интерфейс работал на компьютерах и смартфонах.

На этом этапе используй только демонстрационные данные. Не подключай API, не создавай систему авторизации и не реализуй торговлю.

Сделай интерфейс функциональным: сортировка и фильтры должны работать, а не быть просто декоративными элементами.

После создания объясни, какие компоненты ты реализовал и как устроена страница. Не добавляй функции, которых нет в требованиях.
